What this is not

A browser's number is a browser's number. It is not comparable with the native one: a different runtime, a different clock, a different compiler. What the two runs do share is the match count, and that is the number this page checks.

The column here is rebuilt from a histogram — the counts of the file's eleven distinct discount values — not read from the Parquet file. It has the same multiset as the native column, so the same number of rows match, but the row order is not the file's: the browser has no Parquet reader, and it does not pretend to.

The engine is Columnar Engine — a vectorised columnar query engine in Rust with a measurement harness that is willing to say the engine loses.
